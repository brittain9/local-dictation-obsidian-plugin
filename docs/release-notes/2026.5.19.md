## Highlights

- **One release per version** — the plugin bundle and the native sidecar archives now ship on the same GitHub release tagged `2026.5.19`. Obsidian's auto-updater only consumes `main.js`, `manifest.json`, and `styles.css`; the sidecar archives sit on the same tag for the plugin's installer to fetch on demand.

## Fixes

- Sidecar install URLs no longer route through a separate `sidecar-<version>` tag, removing the version indirection from the previous release scheme.
