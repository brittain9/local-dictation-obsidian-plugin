# Discord post: UI localization release

Local Dictation now speaks your language in Obsidian.

🇺🇸 Local dictation is in your language now.
🇪🇸 El dictado local ya está en tu idioma.
🇩🇪 Lokales Diktieren gibt es jetzt in deiner Sprache.
🇫🇷 La dictée locale est maintenant disponible dans votre langue.
🇵🇹 O ditado local agora está no seu idioma.
🇮🇹 La dettatura locale ora è nella tua lingua.
🇳🇱 Lokaal dicteren is er nu in jouw taal.
🇯🇵 ローカル音声入力があなたの言語で使えるようになりました。

Local Dictation for Obsidian is now localized for 8 languages: English, Spanish, German, French, Portuguese, Italian, Dutch, and Japanese. It keeps high-quality speech-to-text local by default, supports cross-platform desktop Obsidian workflows, and lets you choose local or remote text cleanup when you want it.

Next up: text-to-speech and deeper speech workflows built for Obsidian.

Install: [Obsidian Community Plugin](https://obsidian.md/plugins?id=local-dictation)
Release: [GitHub release](https://github.com/brittain9/speech-kit-obsidian-plugin/releases/latest)
