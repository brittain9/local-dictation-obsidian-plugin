## Highlights

- **Dictation toggle command** — a single command starts and stops a session, so the action can be bound to one hotkey instead of two.
- **Configurable timestamps** — timestamps now have their own settings card with tooltips, compose with LLM post-processing, and the sparse interval acts as a hard time limit instead of a soft hint.
- **Release layout aligned with Obsidian conventions** — the plugin release at this tag ships only `main.js`, `manifest.json`, and `styles.css`. The native sidecar binaries are published from the same CI run under the `sidecar-2026.5.16` tag and are downloaded on demand from the plugin's settings page.
- **Naming cleanup** — the sidecar executable and LLM sidebar now use Local Dictation naming. Saved workspace layouts that referenced the old Local Transcript sidebar may need the pane reopened once.

## Fixes

- LLM post-processing no longer reshuffles the session range while a user edits during batch cleanup.
- LLM post-processing sidebar now reflects the active preset's `minWords` and `temperature` values.
