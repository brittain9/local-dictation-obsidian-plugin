## Highlights

- **Read notes aloud entirely on-device.** Local Dictation can now turn note text into natural speech using Pocket TTS. Dedicated models are available for English, French, German, Spanish, Portuguese, and Italian without sending note content to an external service.

- **Use one command for selections or complete notes.** Bind **Local Dictation: Read aloud** to a hotkey. When text is selected, only that selection is read; otherwise, playback begins at the start of the note.

## Improvements

- **Control playback without another ribbon button.** An active-only status player provides model, speed, voice, pause, resume, and stop controls while reading.

- **Find and understand settings more easily.** Local Dictation settings now participate in Obsidian's settings search. The Models section clearly separates speech-to-text and text-to-speech models, while voice, shortcut, and speed controls live in a dedicated Read aloud section above LLM transformation.

- **Listen to readable Markdown.** Read aloud preserves headings, links, lists, and table text while skipping properties, code, and math.

- **Choose a comfortable listening speed.** Playback supports pitch-preserving speed control from 0.75× to 2×. Changing the model, voice, or speed during playback restarts from the current sentence.

## Fixes

- **Updated vulnerable development dependencies.** Security advisories affecting `brace-expansion`, `fast-uri`, and `js-yaml` are patched, and the Rust and JavaScript development toolchains are refreshed. These dependencies are used to build and validate the plugin; no user action is required.

## Known Limitations

- **Concurrent dictation and playback are not yet supported.** A dictation transcript may wait for active read-aloud playback to stop before it is inserted into the note.
