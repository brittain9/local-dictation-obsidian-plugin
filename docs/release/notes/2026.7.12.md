## Highlights

- **Add Supertonic 3 for multilingual local Read aloud.** Read aloud now supports Supertonic 3 in English, Spanish, German, French, Portuguese, Italian, Dutch, and Japanese. The managed install starts with the F1 voice, offers nine optional built-in voices, and verifies licensed model files before activation.

- **Make CUDA acceleration clearer and lighter.** Published CUDA sidecars now focus on the production Whisper acceleration path, removing 368.7 MiB from the Windows CUDA payload and about 263 MiB from the compressed Windows CUDA archive. Hardware-acceleration controls now appear only when the selected model family can use them.

## Improvements

- **Guide users to the next setup action.** Settings now surfaces one highest-priority action for missing setup, sidecar version drift, compatible CUDA install, or enabling an installed CUDA sidecar. Failed model and optional-voice installs stay visible with **Retry** and **Dismiss**, and Read aloud prompts users to choose a model when its selection is missing.

- **Show richer Read aloud model details.** The selected Read aloud model now has an info button showing supported languages, available and installed voices, speed support, output sample rate, and model-card links without making users hunt through the catalog.

- **Make transcript cleanup reversible from the notice.** When cleanup replaces dictated text, Local Dictation now offers a direct **Restore original** action using the existing in-memory recovery receipt.

## Fixes

- **Avoid wasted startup when dictation cannot insert text.** Starting dictation from a non-Markdown or non-editable target now warns immediately before microphone access, sidecar startup, or stopping active Read aloud.

- **Protect speech from sidecar and model maintenance.** Sidecar installs, updates, restarts, uninstall, acceleration changes, and model removal now respect active Dictation and Read aloud lifecycles instead of interrupting or racing them.

- **Render installation progress accurately.** Model and sidecar progress rows now add and remove byte/detail lines as snapshots change, and expose truthful determinate or indeterminate progress semantics to assistive technology.

## Performance

- **Reuse the loaded TTS model between Read aloud requests.** The synthesis worker keeps one loaded model resident for 90 seconds when files have not changed, avoiding repeated Supertonic/Pocket reloads across nearby playback requests.
