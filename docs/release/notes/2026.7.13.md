# 2026.7.13

## Highlights

- **Local Dictation is now Speech Kit.** The new name reflects what the plugin has become: dictation, meeting transcription, translation, and read aloud in one place. Settings, hotkeys, and installed models carry over automatically, and the plugin keeps its existing Community Plugins listing.
- **Translate notes without leaving Obsidian.** Translate a selection or a whole note between English and Spanish, German, French, Portuguese, Italian, Dutch, or Japanese. A preview shows the result and the language pair before anything changes, so you can replace the text, insert it below, or copy it. Frontmatter, code, math, links, wikilinks, tables, callouts, and list structure are preserved. Translation runs entirely on your machine after one optional model download of about 526 MB that covers every supported direction.

## Improvements

- **Nemotron 3.5 ASR is no longer labeled experimental.** Multilingual live transcription has been reliable in practice, so the model browser and setup guidance now present it as a standard choice.

## Fixes

- **Settings spacing around the Capture heading.** The transient attention banner now participates in Obsidian's native settings group rhythm, so Capture is no longer crowded whether the banner is visible or hidden.
