## Highlights

- **Clearer streaming vs. standard models.** Settings, the model picker, and the setup wizard now spell out which models dictate live (streaming) and which transcribe after a pause. Streaming models carry a "Streaming" badge, each family shows a one-line summary, and the Moonshine model names are simplified.

## Fixes

- **More reliable streaming finalization.** Final transcripts are re-decoded from clean model state instead of reusing an unsound incremental cache, preventing rare corruption of committed text after a pause or a 30-second split.

## Performance

- **Live partials stay responsive on long dictation.** Moonshine partial decoding is now bounded per update instead of growing with utterance length, so responsiveness no longer degrades during long continuous speech.

## Internal

- Added a streaming quality and performance regression suite — word-error and anchor checks, final-equals-one-shot equivalence, revision stability, and silence handling — plus a guard against super-linear partial-decode cost.
- Refreshed the README and architecture docs to cover all three managed model families (Whisper, Cohere Transcribe, and Moonshine).
