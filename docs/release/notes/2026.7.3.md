## Highlights

- **System audio on macOS.** "Include system audio" now works natively on macOS 14.2 and later using CoreAudio process taps — transcribe meetings, calls, and videos without setting up a virtual audio device. Turning the setting on runs a quick readiness check: macOS asks once for System Audio Recording permission, and if your Obsidian installer is too old to request it, the plugin says so and points you at a fresh installer.
- **Smart paragraph controls.** New settings to tune how smart paragraphs split long dictation into readable chunks.
- **Keep LLM cleanup fully local.** Remote LLM routing can now be disabled outright, so transcript cleanup never leaves this computer.

## Fixes

- **Linux system audio is transcribed in real time.** Capture now requests one 20 ms frame per fragment instead of inheriting the audio server's multi-second default, so system-audio speech no longer arrives seconds late.
- **Sturdier session lifecycle.** Sessions tear down cleanly when a model fails to load or capture stops unexpectedly, a sidecar restart race no longer misreports an exit, and streaming decode errors are contained instead of taking down the sidecar.
- **Auto routing measures transcripts correctly** when deciding whether cleanup should route to the larger remote model.
- **Hardened model installs** by removing a model-path traversal risk.

## Performance

- **Faster startup.** The sidecar skips the startup model probe, and LLM provider lists refresh only when the settings tab is opened.

## Internal

- Per-session system-audio delivery diagnostics in the plugin log; only final transcripts are logged, so live-dictation partials no longer flood it.
- A scripted CUDA development setup (`npm run` + `scripts/install-dev-cuda.mjs`) with matching CONTRIBUTING and CUDA guide updates.
- macOS system-audio research and specification committed under `docs/specs/`; dev-tooling dependency updates.
