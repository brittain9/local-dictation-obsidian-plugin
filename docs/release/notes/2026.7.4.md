## Highlights

- **Try dictation from setup.** After setup finishes, select **Try dictation now** to start a real dictation session immediately.

## Improvements

- **Keep dictation in the right note.** Navigating to another note no longer displaces the note receiving your transcript.
- **Clearer recovery guidance.** Setup, sidecar, and dictation failures now provide more actionable feedback.

## Fixes

- **Safer edits after external changes.** If a note changes in a way that invalidates the active insertion point, dictation stops safely instead of writing to the wrong location.

## Internal

- Windows CUDA release caching is now tied to the exact main commit, making release builds more predictable.
