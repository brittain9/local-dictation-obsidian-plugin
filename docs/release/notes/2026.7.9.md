## Highlights

- **Use Local Dictation in your language.** The complete plugin interface now follows Obsidian's language in English, Spanish, German, French, Portuguese, Italian, Dutch, and Japanese. This includes setup, settings, commands, model management, notices, and optional LLM transforms. Regional variants such as `pt-BR` use their matching base-language translation, while other languages continue to receive the full English interface.
- **Positioned for multilingual, local-by-default dictation.** The README and plugin metadata now describe Local Dictation as cross-platform dictation for Obsidian with local speech models, meeting capture, multilingual support, and optional text cleanup.

## Improvements

- **Localization launch copy.** Added a concise Discord announcement for the eight-language UI release, including install and release links plus the text-to-speech roadmap note.
