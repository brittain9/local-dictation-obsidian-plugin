# 2026.8.1

## Highlights

- **Use local or self-hosted language models for refinement.** Add OpenAI-compatible providers such as LM Studio, configure them separately from built-in providers, and route short or long transcripts to the provider you prefer.
- **Turn Always-on dictation into a voice clipboard.** Enable automatic copying to place each accepted final utterance on the system clipboard, ready to paste into another application while Speech Kit keeps listening.

## Internal

- **Releases start sooner.** The release pipeline no longer waits for a duplicate Windows CUDA pre-build before starting the authoritative cross-platform build.
