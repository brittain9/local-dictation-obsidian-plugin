# Pocket TTS Phase 0 reproduction

This directory reproduces the runtime-route decision in
[`docs/specs/tts-pocket.md`](../../docs/specs/tts-pocket.md). It never writes
model weights, generated audio, native binaries, or build output into Git.

## Pinned inputs

- Candle community port: `pocket-tts` 0.6.2.
- ONNX export: `KevinAHM/pocket-tts-onnx` revision
  `58a6d00cf13d239b6748cb0769f35c580a8f606c`.
- Voice states: `kyutai/pocket-tts-without-voice-cloning` revision
  `e041936c75475d350b405bc870bcf7c22da4e9e6`.
- Rust ORT binding: 2.0.0-rc.12, the exact sidecar dependency. It resolved the
  ORT 1.24.2 native distribution during the 2026-07-19 probe.
- Python reference environment: the exact versions in `requirements.txt`.
- Reference runner: `pocket_tts_onnx.py`, 28,816 bytes, SHA-256
  `4381a4396ba08b2626a25a87001e3c51dbacd136e1022d2d40a8cefb14b44be0`.

The Python runner is a correctness and performance oracle only. It is not a
production dependency.

## Commands

Use scratch paths outside the repository:

```sh
scripts/pocket-tts-phase0/build-candle-probe.sh /tmp/pocket-tts-candle-probe

python3 scripts/pocket-tts-phase0/pin_artifacts.py \
  > /tmp/pocket-tts-artifacts.json
cmp /tmp/pocket-tts-artifacts.json scripts/pocket-tts-phase0/artifacts.json

python3 scripts/pocket-tts-phase0/download.py english_2026-04 \
  /tmp/pocket-tts-models --include-reference-runner

scripts/pocket-tts-phase0/build-onnx-probe.sh \
  /tmp/pocket-tts-models/english_2026-04 /tmp/pocket-tts-ort-probe

uv run --python 3.10 \
  --with-requirements scripts/pocket-tts-phase0/requirements.txt \
  scripts/pocket-tts-phase0/bench.py \
  /tmp/pocket-tts-models/english_2026-04 \
  /tmp/pocket-tts-english-int8.wav --threads 2
```

Repeat the benchmark with `--threads 0` for ORT defaults, with
`--precision fp32` after adding the three fp32 graphs, or with a downloaded
`french_24l` bundle for the larger-model check. WAVs are disposable evidence
and must remain outside Git.

## Measured result

Host: Fedora Linux, Intel Core i5-12600K (10 cores / 16 logical CPUs), Rust
1.94.1. All RTF runs used seed 288, temperature 0.3, and one LSD step.

| Candle size probe | stripped bytes | gzip -9 bytes |
|---|---:|---:|
| Baseline | 355,672 | 172,670 |
| With `pocket-tts` | 7,144,720 | 2,568,140 |
| Delta | 6,789,048 | 2,395,470 |

The 2.28 MiB compressed delta passed the 20 MiB size gate, but the crate could
not load the pinned English model. It failed on
`mimi.downsample.conv.conv.weight`: expected `[512, 512, 32]`, received
`[32, 512, 32]`. Its advertised quantized constructors also load the normal
model and report `is_quantized() == false`.

| Route / model | threads | audio | generation | RTF | real-time multiple |
|---|---:|---:|---:|---:|---:|
| ONNX INT8 English | 2 | 10.08 s | 3.260 s | 0.323 | 3.09x |
| ONNX INT8 English | ORT default | 10.08 s | 4.555 s | 0.452 | 2.21x |
| ONNX FP32 English | 2 | 10.32 s | 3.902 s | 0.378 | 2.65x |
| ONNX FP32 English | ORT default | 10.32 s | 8.043 s | 0.779 | 1.28x |
| ONNX INT8 French 24-layer | 2 | 9.60 s | 10.251 s | 1.068 | 0.94x |
| ONNX INT8 French 24-layer | ORT default | 9.60 s | 14.381 s | 1.498 | 0.67x |

The decoder produces mono float32 samples at 24 kHz. The harness writes
24-kHz mono PCM16 WAVs. Pocket TTS exposes temperature, flow-step, and EOS
controls but no generation-side speaking-rate control.

At deterministic temperature zero, the ONNX fp32 waveform matched Kyutai's
reference at correlation 0.999979, 43.84 dB SNR, and 0.000496 RMSE. The
maintainer found no material audible fp32-to-INT8 regression in the labeled
comparison; INT8 is therefore the selected artifact precision, with the
shipping Whisper round-trip test remaining the regression gate.

## Artifact contract

`artifacts.json` is generated by `pin_artifacts.py` from the Hugging Face
`paths-info` API and is the complete size/SHA-256/URL record for all six D2
variants. It intentionally excludes `mimi_encoder.onnx`: that graph was loaded
successfully during Phase 0, but only supports voice cloning, which Stage A
does not expose. The production runtime uses precomputed safetensors voice
states.
